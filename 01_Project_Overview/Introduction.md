# Project Introduction

## System Name

Smart Service Management System (SSMS)

## Background

The increasing demand for faster customer service requires organisations to manage service requests efficiently.

Traditional methods such as emails and spreadsheets can cause delays and difficulty in monitoring service performance.

Therefore, this project proposes a centralized system that allows customers, staff, and administrators to manage service operations effectively.

## Project Scope

The system covers:

- User management
- Service request management
- Staff assignment
- Status tracking
- Reporting dashboard
